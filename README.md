# 👾 Tamagotchi (Bichinho Virtual em Java)

Um projeto simples de **Bichinho Virtual (Tamagotchi)** desenvolvido em Java para praticar conceitos fundamentais da Orientação a Objetos e manipulação de estado do objeto.

---

## 📌 Sobre o Projeto

O objetivo do projeto é simular o comportamento de um pet virtual. O usuário fornece o nome e os atributos iniciais de **fome** e **energia**, e o sistema calcula automaticamente o **humor** do pet com base nessas informações.

### 🎯 Funcionalidades

* **Definição de Atributos:** Controle de fome e energia dentro da escala de 0 a 100.
* **Cálculo Automático de Humor:**
  * **Triste:** Energia abaixo de 25 e Fome acima de 75.
  * **Cansado:** Energia abaixo de 50 e Fome acima de 50.
  * **Feliz:** Qualquer outra combinação de estado.
* **Interações do Pet:** Métodos de interação simples como `bater()` e `assoprar()`.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java
* **Paradigma:** Orientação a Objetos (POO)
* **Recursos do Java Moderno:** Uso de `java.lang.IO.*` (Preview Features / Implicitly Declared Classes)
